# Guess the Number

[English](README.md) · [Русский](README.ru.md)

Цветная консольная игра на Go: угадайте число, которое загадал компьютер.

## Возможности

- Три уровня сложности: лёгкий, средний и сложный
- Цветной вывод в терминале
- Чистый экран в каждом раунде
- Счётчик попыток

## Начало работы

Нужен [Go](https://go.dev/dl/).

```bash
go run guess.go
```
